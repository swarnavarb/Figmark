## Problem

The token comment says "Two durations, one curve, everywhere"
(`app/src/styles.css:360`), but the sheets hold **31 distinct `cubic-bezier`s**.
About 60 of them are overshoot curves (`y1 > 1`) standing in for a spring, in
at least eight near-identical variants:

```
24× cubic-bezier(0.34, 1.56, 0.64, 1)   15× cubic-bezier(0.34, 1.4, 0.64, 1)
 3× cubic-bezier(0.3, 1.4, 0.5, 1)       3× cubic-bezier(0.3, 1.3, 0.5, 1)
 2× cubic-bezier(0.34, 1.7, 0.5, 1)      1× cubic-bezier(.3,1.6,.5,1) …
```

A cubic-bezier can overshoot once and has no settle; it reads as "boing", not
as mass. Some are on press feedback, where a 140ms overshoot is too short to
read as anything but a twitch:

```css
/* app/src/styles.css:6117 — current */
transition: color var(--dur-2) var(--ease), transform var(--dur-1) cubic-bezier(0.34, 1.56, 0.64, 1);
/* app/src/styles.css:6134 */
transition: border-color var(--dur-1), color var(--dur-1), background var(--dur-1), transform var(--dur-1) cubic-bezier(0.34, 1.56, 0.64, 1);
/* app/src/styles/FeedPage.css:111 (.qheart) */
transition: transform var(--dur-1) cubic-bezier(0.34, 1.56, 0.64, 1), …
```

And the segmented control thumbs run a 420ms bouncy slide on a control people
flip back and forth (frequency: tens of times per session):

```css
/* app/src/styles.css:8959 (.csheet__thumb) */
transition: transform 420ms cubic-bezier(0.34, 1.4, 0.64, 1), background var(--dur-2) ease;
/* app/src/styles/FeedPage.css:144 (.qkinds__slot) */
transition: transform 420ms cubic-bezier(0.34, 1.56, 0.64, 1), width 420ms cubic-bezier(0.34, 1.56, 0.64, 1);
```

Also `.lp` redefines `--spring` locally as the drawer curve
(`app/src/styles.css:6521`), which is not a spring — the name will collide.

## Target

Spring physics, sampled from the real damped-spring equation
(Apple model: perceptual duration + bounce, ζ = 1 − bounce) into CSS `linear()`.
Transitions keep retargeting mid-motion, so they stay interruptible.

Add to `:root` in `app/src/styles.css`, after `--ease-out`:

```css
  /* Springs, sampled from a damped spring into linear(). Each pairs with its
     own duration: the time the spring takes to settle, not a guess.
     snappy = { duration: 0.3, bounce: 0.1 } – toggles, thumbs, press release
     bouncy = { duration: 0.4, bounce: 0.3 } – rewards, hearts, playful pops */
  --spring-snappy: var(--ease-out);
  --spring-snappy-dur: 260ms;
  --spring-bouncy: cubic-bezier(0.34, 1.4, 0.64, 1);
  --spring-bouncy-dur: 450ms;
}
@supports (transition-timing-function: linear(0, 1)) {
  :root {
    --spring-snappy: linear(0, 0.009, 0.033, 0.068, 0.111, 0.16, 0.213, 0.267, 0.322, 0.376, 0.429, 0.48, 0.529, 0.575, 0.618, 0.658, 0.695, 0.729, 0.76, 0.788, 0.814, 0.837, 0.858, 0.876, 0.893, 0.908, 0.921, 0.932, 0.943, 0.951, 0.959, 0.966, 0.972, 0.977, 0.981, 0.985, 0.988, 0.99, 0.993, 0.995, 1);
    --spring-bouncy: linear(0, 0.014, 0.053, 0.11, 0.179, 0.255, 0.336, 0.417, 0.496, 0.573, 0.644, 0.709, 0.768, 0.821, 0.867, 0.907, 0.94, 0.968, 0.99, 1.008, 1.022, 1.032, 1.039, 1.043, 1.046, 1.046, 1.045, 1.043, 1.04, 1.037, 1.033, 1.03, 1.026, 1.022, 1.019, 1.016, 1.013, 1.01, 1.008, 1.006, 1);
  }
}
```

(Values generated by sampling x(t) = 1 − e^(−ζωt)(cos ω_d t + (ζω/ω_d) sin ω_d t),
ω = 2π/duration, 41 points to a 0.4% settle tolerance.)

Mapping:

| Where | Becomes |
| --- | --- |
| Press feedback using an overshoot at `var(--dur-1)` (6117, 6134, FeedPage.css:111, 4454) | `transform 160ms var(--ease-out)` — press feedback does not bounce |
| Segmented thumbs (8959, FeedPage.css:144, FloatingCalc.css:163) | `transform var(--spring-snappy-dur) var(--spring-snappy)`; drop the `width` transition on `.qkinds__slot` only if step 4 says so |
| Every other `transition` whose transform easing is `cubic-bezier(0.3x, 1.x, …)` | `transform var(--spring-bouncy-dur) var(--spring-bouncy)` |
| `@keyframes` animations using overshoot curves | **Leave** — `linear()` applies per keyframe segment and would change multi-step pops; out of scope |

## Repo conventions to follow

- Tokens live in the first `:root` block of `app/src/styles.css` (around line 360) with a one-line comment each.
- Exemplar of a token in use: `app/src/styles.css:10368` `transition: transform 600ms var(--ease-out);`

## Steps

1. Add the four tokens and the `@supports` block above to `app/src/styles.css`.
2. Update the token comment at `styles.css:360` to: `/* Motion. Two durations, two curves, two springs. */`.
3. In `app/src/styles.css:6521` rename the local `--spring` to `--lp-ease` and `--bounce` to `--lp-bounce`; replace every `var(--spring)` / `var(--bounce)` in `styles.css` lines 6500–6700 accordingly (grep: `grep -n 'var(--spring)\|var(--bounce)' app/src/styles.css`).
4. Apply the mapping table to every line listed by:
   `grep -rnE 'transition:[^;]*cubic-bezier\(0\.[0-9]+, ?1\.[0-9]+' app/src --include=*.css`.
   For `.qkinds__slot` keep `width` but give it the same spring as `transform`.
5. Leave the reduced-motion blocks untouched — they already set `transition: none`.

## Boundaries

- Do NOT touch `@keyframes` or `animation:` declarations.
- Do NOT change any non-transform easing in the same declaration.
- Do NOT add a JS spring library.
